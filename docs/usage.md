# 使用说明

[English](usage.en.md) | 简体中文

## 设置学期和课程

第一次使用默认预选 English 与 USD，不跟随系统语言；请确认语言与学费实际使用的货币。之后可通过主页面课程右侧的语言 / 货币按钮修改。取消不会保存，下次启动仍会询问。升级保留已保存的语言和货币选择，切换货币不会换算学费。

打开右上角齿轮，填写学期总学费、开始日期和结束日期，再按星期添加课程。每门课需要名称、上课时间、整数小时和分钟。分钟范围为 0 至 59，每节课至少 1 分钟、最多 24 小时，可以跨午夜。

每门课可以设置独立起止日期，留空则沿用学期日期。停课日期按 `YYYY-MM-DD` 填写，多日用逗号分隔，必须是该课程日期范围内的上课日。程序按实际课次判断重叠；前后半学期同一时间的不同课程可以共存。

设置面板预览总课时、学期天数、周数和每秒价值。学期起止日都包含在范围内，首日算第 1 周，此后每 7 天一周。日期范围由你填写，或由导入课程的首末课日推算，不代表程序已核实学校的官方学期安排。

点击“保存学期与课表”并等待成功后，新课表生效。点击取消、关闭设置或按 Esc 会放弃未保存的编辑。西班牙语支持小数逗号，例如 `1234,56`；请勿使用千位分隔符。

## 计时与窗口

正在上课时自动显示本节课；无课时显示下一节课及开课倒计时，本节课金额归零。最后一节课结束后保留最后一节结果。学期累计只计入完整结束的课次，包含首次打开程序之前的课次。

桌面窗口默认 480 × 420，最小 400 × 360。拖动顶部空白或日期时钟区域移动窗口，双击顶部切换最大化。右上角依次为置顶、设置、最小化、最大化和关闭。置顶仅作用于当前窗口，关闭重开默认取消。

最大化后，上课时显示“好好上课！”，课前、课间、停课及学期结束等状态显示“好好休息！”。小窗口隐藏这行提示。

金币按本节课未舍入金额计算，每满 10 个所选货币单位一枚，最多绘制 600 枚；换课后重新计算。恢复窗口时直接显示当前金额和金币堆。系统启用“减少动态效果”时直接更新数字与金币，动画落稳后不持续运行动画帧。

07:00（含）至 19:00 使用浅色，其余时间使用深色。配色按设备本地时钟决定，不根据日出日落或地理位置计算。

## 导出与恢复 JSON

在设置中点击“导出已保存配置”，保存完整 JSON。备份包含学费、学期、课程独立日期、停课日期和货币信息。浏览器迁移到桌面版时，先在原浏览器、原地址导出，再在桌面版导入。

点击“导入 JSON / ICS”，选择 JSON，核对预览中的课程数量、总课时、学费和日期，再确认恢复。取消或导入损坏文件不会覆盖现有配置。备份中的货币与当前货币不同时，需要先修改当前货币，再重新导入；旧备份未记录货币时按 USD 处理。

当前课表格式为版本 4。版本 3 在内存中迁移，确认保存后才写入；版本 1、2 只载入为待补全草稿。未知版本和损坏文件会保留原文件。旧版小数时长若包含秒，编辑时会提示舍入到整分钟，保存后才生效。

桌面版分别保存 `configuration.json` 和 `preferences.json`。保存时先写临时文件、刷新磁盘，备份旧文件的原始字节，再原子替换。备份名为 `configuration.previous-时间戳.json` 或 `preferences.previous-时间戳.json`。保存失败会保留编辑并允许重试；保存过程中阻止关闭窗口。

直接运行的 EXE 与安装版共用 `%APPDATA%\com.mason.tuition-payback\`，数据不跟随 EXE 放在当前文件夹。网页使用当前浏览器的 localStorage，换浏览器、主机名或端口会看到独立的数据。

## ICS 支持范围

导入 ICS 后先核对预览。点击“确认载入课表”只替换编辑区课表并沿用已填学费；补填或核对学费后，点击普通保存才写入。ICS 自身不包含学费，完整迁移请使用 JSON。

支持：

- 有明确 `DTSTART` / `DTEND` 的单次事件。
- `FREQ=WEEKLY`，有 `UNTIL` 或 `COUNT` 结束条件，`INTERVAL` 省略或等于 1，支持多个 `BYDAY`。
- `EXDATE` 停课日期、ICS 折行和文本转义。
- 本地浮动时间，或与设备一致的 IANA `TZID`。
- 单次 UTC 事件转换为设备本地时间。

不支持的规则会导致整个文件被拒绝，包括隔周、月度或无限重复、`RDATE`、单独改期或取消、全天事件、秒级时间、重复事件版本、每周 UTC 重复，以及不同课程时区。实际重叠的课程也需要先处理。

每个文件最多 1 MB，最多 500 个事件及 500 个课表条目。导入文件保持原样。停课后若有补课，需要按已确定的日期调整课表，程序不会猜测补课时间。

## 命令行转换器

```sh
node scripts/convert-nyu-calendar.mjs INPUT.ics TUITION OUTPUT.json
```

此辅助脚本只适用于 `America/New_York` 时区、单个 `BYDAY` 和明确 `UNTIL` 的固定每周 NYU 日历，不是应用内的通用导入器。它不联网，输出路径必须是新文件。输出可导入应用后继续核对和编辑；生成的 JSON 未标注货币时按 USD 处理。
